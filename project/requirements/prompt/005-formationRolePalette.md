# Source prompt — Requirement 005

The user supplied a screenshot showing Football Manager role labels in six
colour families and requested:

> I'd like to use this colour palette when discussing the roles within a
> tactic. There are rows defined in the formation display that align with
> these colours: goalkeeper, defence, DM, midfield, AM and striker. Ignore the
> dropdown arrow from the screenshot; we will want to create a simple icon to
> represent the role based on these.

The reference examples included BGK, CB, DLP, AWB, WM, IF, FR and CHF. The
dropdown arrow and adjoining split-button treatment are explicitly excluded.

The user further clarified the intended player presentation:

> When we look at a player view, instead of the position text D(C), for example,
> we would see the icon with BCB in it, for Ball-Playing Centre-Back.

This makes the icon a tactic-specific assigned-role presentation. It does not
replace or discard the player's underlying natural-position data.
