# FMSAT sample screenshots

Place user-supplied PNG or JPEG Club Information, Formation, In Possession, Out of
Possession and Squad Attributes screenshots in `fmsat/samples/`.
Screenshots are deliberately not embedded in source code or committed by default.

Capture each complete screen at native resolution. Keep the tactic name visible on the
Formation screenshot and keep column headers visible on the Squad Attributes screenshot.

When creating a squad, capture the Club Information screen with the full club badge clearly
visible. FMSAT previews and stores this screenshot for the squad's workspace image; it does
not run OCR on it. Do not substitute a tactic Formation screenshot for the squad image.
